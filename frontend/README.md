# 平台前端

本目录用于建设课程思政案例库的自研前端页面和交互。

## 主要职责

- 登录和角色相关页面；
- 案例列表、筛选和详情；
- 教师案例创建、编辑和提交；
- AI 案例生成及结果编辑；
- 智能评价结果展示；
- 管理员审核和基础数据管理；
- 加载、空状态、错误和权限提示。

## 接口边界

- 前端只调用自研业务后端；
- 不直接调用 MaxKB 管理接口或聊天接口；
- 不保存 MaxKB API Key、模型密钥或数据库密码；
- 开发初期依据 `contracts/` 中的 OpenAPI 和 Mock 数据工作；
- 真实接口完成后再切换并进行联调。

## 当前状态

前端技术栈、组件库和页面清单尚未最终确认。本目录暂不提供启动命令，待任务 3 完成技术选型和工程初始化后补充。
