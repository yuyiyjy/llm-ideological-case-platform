基于角色的功能划分
按学生、教师、管理员三类角色拆分完整功能，边界清晰、区分明显
一、学生角色（仅学习查阅，无生成、无管理权限）
1. 账号基础功能
账号登录、查看 / 修改个人基础信息
修改登录密码
2. 案例浏览查阅核心功能
首页查看平台推荐思政案例
关键词检索全部公开已审核案例
按课程、思政主题、标签多维度筛选案例
分页查看案例卡片，点开查看完整案例详情
收藏感兴趣案例，进入「我的收藏」统一查看
查看当前案例的同类相关推荐案例
3. 权限限制（学生不能做）
无法使用 AI 生成案例功能
无法提交案例入库
没有任何后台管理、审核、数据操作权限
二、教师角色（浏览 + AI 生成 + 自主提交案例，无后台管理）
1. 账号基础功能
登录、编辑个人信息、修改密码
2. 通用浏览功能（和学生共用）
首页推荐案例浏览
关键词 + 多条件检索全部公开案例
查看案例完整详情、收藏案例、查看收藏列表
查看同类相关案例推荐
3. 教师独有：AI 智能案例生成模块（学生没有）
选择对应专业课程、填写专业知识点、选定思政导向
调用大模型实时生成定制思政案例，流式展示生成内容
对生成内容进行编辑、复制、文本导出
保存本次生成记录，在「我的生成记录」随时回看
可将满意的生成案例提交审核，等待管理员审批入库
4. 教师独有：自主上传案例
手动填写完整思政案例信息（标题、课程、思政点、正文等）
提交自制案例进入审核队列
5. 权限限制（教师不能做）
不能审核案例、不能下架 / 删除平台公共案例
不能管理课程、思政标签、用户账号
看不到平台数据统计、后台看板
三、管理员角色（拥有全部浏览 + 生成 + 后台管理权限）
1. 通用基础功能（同教师）
账号登录、修改个人信息、密码
正常浏览、检索、收藏平台所有公开案例
正常使用 AI 案例生成功能，保存个人生成记录
2. 管理员独有：案例审核与全量管理
查看所有待审核案例（教师上传、AI 提交的案例）
审核操作：通过 / 驳回案例，驳回可填写原因
管理全部入库案例：编辑、下架、删除、批量导入导出案例
3. 管理员独有：分类标签体系管理
新增 / 编辑 / 删除课程分类
维护五大思政指标体系
增删各类思政标签
4. 管理员独有：全平台用户管理
查看所有学生、教师账号列表
分配 / 修改用户角色（学生↔教师）
冻结异常账号、重置用户密码
5. 管理员独有：数据统计看板
平台总案例数量、各课程案例分布统计
AI 生成使用次数统计
案例浏览热度、用户活跃度数据查看
三类角色核心差异总结
学生：只能看、收藏，不能生成、提交、管理
教师：能浏览 + AI 生成 + 提交案例，无后台审核、用户、分类管理权限
管理员：具备全部使用功能，外加整套平台后台管控、审核、数据权限
