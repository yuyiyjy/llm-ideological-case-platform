# 项目文档

本目录保存需要长期维护和共同查阅的项目文档。

## 计划内容

- 系统架构与模块边界；
- 数据库 ER 图和字段说明；
- API 与数据流说明；
- 技术选型和架构决策记录；
- 会议结论和需求变更；
- 本地开发、联调和部署说明；
- 测试、备份、恢复和项目交付文档。

## 文档原则

- 记录已确认结论，并标明待确认事项；
- 重大技术决定应包含背景、选项、结论和影响；
- 不把聊天记录作为唯一决策依据；
- 命令和启动步骤必须实际验证；
- 文档引用字段或接口时，应链接到 `contracts/` 中的权威契约；
- 过期文档应标明状态，不应静默覆盖重要历史决定。
