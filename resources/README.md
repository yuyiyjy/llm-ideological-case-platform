# 项目资源

本目录保存项目开发所需的数据标准、标签字典、评价规则、提示词和少量脱敏样例。

## 可以保存

- 案例字段规范；
- 专业、课程、知识点和思政标签字典；
- 案例评价维度、评分规则和等级说明；
- 生成与评价 Prompt 的版本化文本；
- 用于测试的少量脱敏案例；
- 数据导入格式说明和验收规则。

## 不应保存

- 大量未经筛选的原始网页和文件；
- 含个人隐私、账号或联系方式的数据；
- 未确认授权的版权材料；
- 真实用户上传内容；
- MaxKB 数据卷或业务数据库导出；
- 密钥、密码和内部访问地址。

## 管理原则

- 规范文件应包含版本号和更新时间；
- 样例数据应注明来源、用途和是否经过脱敏；
- 一级标签、二级标签和自由文本关键词不得混用；
- 数据规范修改后，应同步检查 Schema、Mock、数据库和工作流；
- 大文件如确需保存，应先讨论存储方式，不直接提交到 Git。
