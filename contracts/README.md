# 共享契约

本目录保存前端、后端、数据和 MaxKB 工作流共同依赖的接口与数据契约。

## 计划内容

```text
openapi/     业务 API 定义
schemas/     案例、生成请求、评价结果等 JSON Schema
mocks/       前端开发使用的脱敏 Mock 数据
changes/     字段和接口变更记录
```

以上子目录在产生实际文件时再创建，不为未来可能使用的内容预建空目录。

## 管理原则

- 共享字段必须在这里明确名称、类型、是否必填和业务含义；
- Mock 与真实接口应保持同一结构；
- MaxKB 原始返回不得直接作为前端契约；
- 字段、状态或错误码变更必须记录原因和兼容性影响；
- 任务 1、任务 2、任务 3 和任务 4 共同确认的结论才可视为稳定契约；
- 禁止通过口头约定长期维护不同版本的字段。
