# 跨模块测试

本目录用于保存跨模块、跨服务和可重复执行的项目级测试。

## 计划范围

- OpenAPI 和 JSON Schema 契约测试；
- 前后端接口集成测试；
- 业务数据库与 MaxKB 映射测试；
- 案例导入和字段合法性测试；
- RAG 固定问题集与检索结果评测；
- 生成和评价工作流回归测试；
- 权限、异常和部署冒烟测试。

模块内部单元测试可以保存在对应模块内，例如后端单元测试可放在 `backend/tests/`。本目录重点处理跨模块验证。

## 测试原则

- 测试数据必须脱敏且可重复使用；
- 固定评测集应记录期望结果和版本；
- 模型、Prompt、知识库或检索参数变化后应执行回归测试；
- 测试不能依赖某位成员电脑上的隐含配置；
- 失败结果应能够定位到接口、案例、工作流或配置版本。
